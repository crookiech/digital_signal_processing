# GUI для настройки и управления мультиметром UT8805E
## Команды 
### Настройка измерения (DCV)
- `CONF:VOLT:DC` — сконфигурировать прибор для измерения постоянного напряжения.
- `VOLT:DC:RANG:AUTO ON` — включить автоматический выбор диапазона (200 мВ ... 1000 В).
- `VOLT:DC:RANG <V>` — установить фиксированный диапазон вручную (например, `2` для 2В).
- `VOLT:DC:NPLC <FAST|MED|SLOW>` — установить скорость измерения (быстро/средне/медленно).
- `VOLT:DC:IMP:AUTO ON` — включить высокий входной импеданс Hi-Z (>10 ГОм).

### Чтение данных
- `READ?` — запустить новое измерение и вернуть результат (используется в цикле опроса).
- `FETC?` — прочитать последнее измеренное значение из буфера прибора.

### Математика и статистика
- `CALC:AVER:STAT ON` — включить функцию статистики.
- `CALC:AVER:AVER?` — запросить среднее арифметическое значение.
- `CALC:LIM:STAT ON` — включить проверку пределов.
- `CALC:LIM:LOW <V>` / `CALC:LIM:UPP <V>` — установить нижний и верхний пределы.
