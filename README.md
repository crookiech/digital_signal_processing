# GUI для настройки источника питания UDP3305C
## Команды:
- 'CH1:VOLTage <V>' - установить напряжение на CH1
- 'CH2:VOLTage <V>' - установить напряжение на CH2
- 'CH1:CURRent <A>' - установить ток на CH1
- 'CH2:CURRent <A>' - установить ток на CH2
- 'OUTPut ON' - включить выход
- 'OUTPut OFF' - выключить выход
