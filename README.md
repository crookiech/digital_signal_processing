# GUI для настройки источника питания UDP3305C
## Команды:
- 'CH1:VOLTage <V>' - установить напряжение на CH1
- 'CH2:VOLTage <V>' - установить напряжение на CH2
- 'CH1:CURRent <A>' - установить ток на CH1
- 'CH2:CURRent <A>' - установить ток на CH2
- 'OUTPut ON' - включить выход
- 'OUTPut OFF' - выключить выход
- 'CH1:VOLTage?' - прочитать установленное напряжение на CH1
- 'CH2:VOLTage?' - прочитать установленное напряжение на CH1
- 'CH1:CURRent?' - прочитать установленный ток на CH1
- 'CH2:CURRent?' - прочитать установленный ток на CH2
- 'INStrument CH3' - выбрать CH3 для работы
- 'VOLTage?' - прочитать установленное напряжение на выбранном канале
- 'CURRent?' - прочитать установленный ток на выбранном канале
