# Измерительная система

Приложение на Python / PyQt6. Главное меню открывает независимые окна
мультиметра UT8805E и источника питания UDP3305C. Их можно использовать одновременно.

Папка проекта может называться произвольно, например
`digital_signal_processing-measurement-system`. Запускайте команды из папки,
в которой находятся `main.py` и `requirements.txt`.
Для установки зависимостей нужен доступ в интернет.
Используется Python 3.12. На Windows перед открытием главного окна приложение
проверяет системный VISA-бэкенд и Npcap. Если компонента нет, автоматически
запускается соответствующий установщик из папки `drivers`. Подтвердите запрос
прав администратора Windows и пройдите шаги установщика. Приложение дождётся
его завершения, повторит проверку и откроет главное окно. Если оба компонента
уже доступны, повторная установка не запускается.

Клонируйте всю папку `drivers`: для NI-VISA нужны также `Products`,
`SupportFiles` и файлы конфигурации. При отмене или ошибке установки приложение
покажет причину. Если установщик требует перезагрузку Windows, выполните её
и снова запустите `python main.py`. Драйвер USB–RS232-переходника устанавливается
отдельно для его модели: универсального установщика в комплекте нет.
Автопроверка добавлена для Windows; на других ОС драйверы настраиваются отдельно.

Первоначальная установка зависимостей:

```powershell
python -m pip install -r requirements.txt
```

Запуск из этой же папки:

```powershell
python main.py
```

Если вы используете виртуальное окружение `.venv` внутри этой папки:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

Из другой папки можно указать полный путь к скрипту:

```powershell
python "C:\\Users\\user\\Desktop\\digital_signal_processing-measurement-system\\main.py"
```

Если папка называется `measurement_system`, из родительской папки также
поддерживается `python -m measurement_system.main`.

## Структура

- `main.py` — единая точка входа и управление приложением; запуск из текущей папки.
- `main_menu.py` — четыре категории приборов, карточки и кнопка общей записи логов.
- `shared/devices.py` — описание устройств и три состояния карточек.
- `shared/sessions.py` — владение окнами, повторное открытие и завершение сессий.
- `shared/discovery.py` — фоновое обнаружение USB VISA и COM-портов.
- `shared/registry.py` — сохранённые приборы, серийные номера и состояния карточек.
- `shared/transport.py` — параметры USB/RS232 и защита ресурсов от одновременного открытия.
- `multimeter/` — рабочий интерфейс из ветки `digital_multimeter`, LAN/DHCP и опрос.
- `power_supply/` — рабочий интерфейс из ветки `power_supply`, VISA и поток команд.
- `dac/` — адаптер готового GUI ЦАП/АЦП .
  Карточка «Тест» колонки «ЦАП/АЦП» открывает окно-заглушку с сохранением сессии.
